# Project-Tester-For-Web

Web application used as the target system for automated testing with Robot Framework.

## Purpose

This project provides the web application that receives and processes test actions
from the Robot Framework test project.

The detailed test cases, test scenarios, and test results are maintained separately
in the Robot Framework repository.
